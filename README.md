## ✨ 功能特性

- 📥 **下载测速**：真实字节数下载测速，结果准确
- 📤 **上传测速**：按实际发送字节数计速（已修复上传速度虚高 bug）
- 📡 **Ping / 抖动**：延迟与稳定性一目了然
- 🌐 **IP 归属查询**：自动识别当前网络出口 IP 与归属地
- 🗺 **多节点延迟**：探测多个节点延迟，判断网络路径质量
- ⏱ **持续测速**：长时间连续测速模式，观察网络波动曲线
